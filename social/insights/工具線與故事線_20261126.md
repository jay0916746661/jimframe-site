# 工具線與故事線：八個頻道的分工規格

接 `選題交叉分析_20261126.md`。分析日 2026-11-26，資料為 11/19 與 11/25 兩份 insights 快照。

## 為什麼要分兩條線

11/19–11/25 六天，每千次觀看換到的追蹤者：

| 頻道 | 新增觀看 | 追蹤增 | 每千觀看漲粉 |
|---|---|---|---|
| 咖啡101 | 16,216 | +217 | **13.4** |
| 社交舞101 | 5,793 | +58 | 10.0 |
| 酒精的故事 | 2,205 | +8 | 3.6 |
| 讀完之後 | 937 | +3 | 3.2 |
| 爵士101 | 34,748 | +76 | 2.2 |
| 六弦101 | 13,171 | +25 | 1.9 |
| 藝術101 | **67,310** | +60 | **0.9** |
| 觀光客 | 4,590 | +4 | 0.9 |

藝術101 的觀看是咖啡101 的 4.2 倍，追蹤成長卻只有它的 28%。
**瓶頸不在觸及，在「看完為什麼要追蹤」。**

咖啡101 是唯一兩條線都有的頻道：

| 故事線（帶觀看） | 工具線（帶追蹤） |
|---|---|
| 肯亞品種的祖先是一棵活下來的樹 | 阿拉比卡 vs 羅布斯塔差在哪 |
| 1958 薩爾瓦多的咖啡相親 | 買豆先看烘焙日期不是有效期限 |
| 曼特寧為什麼有土味 | 拿鐵、卡布、小白的奶泡差別 |

故事讓人看完覺得有趣，工具讓人覺得「以後還會用到」。
**只有後者是按追蹤的理由。**

旁證：舊貼文佔新增觀看的比例，咖啡101 58%、藝術101 32%、其餘都在 15% 以下。
工具型內容有長尾，故事型發完就過去。

## 做法：工具線走輪播，不走 Reel

咖啡101 帶來追蹤的貼文全部是輪播（FEED），不是 Reel。
這件事剛好解決成本問題：

- **故事線＝Reel**：已有 214 支待發，排到 2027/2/5，照原排程發，不用再做。
- **工具線＝輪播**：不用配音、不用渲染影片、不花 ElevenLabs 點數。

所以工具線是在 12/13 降級之後**唯一還做得起的新內容**。

寫稿可派 Gemini，版面可派 GPT（照 `ai-dispatch` 的分工），Claude 只定稿。

## 各頻道規格

每個頻道的工具線都要是**連載**，不是零散的單則——連載才給人追蹤的理由。
建議一週一則，先做 4–6 則一個系列。

### 藝術101　優先度最高
觀看最多、轉換最差，改善空間 15 倍。台北在地是它的優勢
（台南雙年展地圖那則分享 19，是全頻道最高）。

- 故事線：一幅畫 ＋ 一個一句話講得完的反轉（已驗證）
- 工具線「看展指南」：
  1. 本月台北有哪些展，一張圖看完
  2. 三句話分辨印象派、後印象派、表現主義
  3. 美術館怎麼看才不會兩小時就累
  4. 畫廊可以直接走進去嗎，要不要問價
  5. 台北各館的票價、聯票與免費時段

### 六弦101
你本人是樂器業務，這條線別人做不來，是整個矩陣裡最難被複製的優勢。

- 故事線：有名的人 ＋ 有名的琴（已驗證）
- 工具線「買琴的人該知道的」：
  1. 單線圈 vs 雙線圈：聲音差在哪，各適合什麼
  2. 桃花心木、梣木、楓木，聽起來真的有差嗎
  3. 一萬、三萬、十萬，各該買什麼
  4. 弦距與琴頸弧度到底影響什麼
  5. 買二手琴要檢查的五個地方

### 爵士101
已經有一則工具型爆款（「八分音符為什麼會搖」2,365），只是沒成系列。
網站有節奏遊戲與和聲遊戲，工具線可以導流過去。

- 故事線：具體的現場動作（關燈、撞彎小號、丟銅鈸）
- 工具線「聽得懂爵士」：
  1. 八分音符為什麼會搖（已驗證，當第一集重發或接續）
  2. 一首標準曲的結構：頭、即興、尾
  3. 台上五個人各自在幹嘛
  4. 入門十張專輯，照年代排
  5. 現場什麼時候該拍手

### 觀光客沒說的事　最缺工具線
轉傳效率全站最低（每千次觀看 4.4 次收藏＋分享），
現有內容是「某景點的真相」，看完就算了，沒有留存價值。

- 故事線：景點的真相 ＋ 有對立的人（河內火車街 2,832、特雷維噴泉 1,289）
- 工具線「行前決策」：
  1. 這個城市哪個月去
  2. 機場到市區三種方式的時間與錢
  3. 換匯在哪換、帶多少現金
  4. 三天兩夜怎麼排不會累
  5. 這個國家的交通卡怎麼買

### 酒精的故事
- 故事線：物件的來龍去脈（波本桶 1,519 是第二名的 7 倍）
- 工具線「怎麼選怎麼喝」：
  1. 威士忌 800／1500／3000 各買得到什麼
  2. 看懂酒標：年份、桶型、酒精度
  3. 調酒基酒六支，先買哪三支
  4. 便利商店買得到的，哪幾支值得

### 社交舞101
每千漲粉 10.0 是第二高，因為它背後有真實社群。
注意：**「這集的舞｜」這個開頭格式是低觀看的標記**，最低四支有三支是它，該拿掉。

- 故事線：時事爭議、被禁的歷史（搖擺舞爭議 2,979、Bachata 被封殺 796）
- 工具線「第一次跳舞的人」：
  1. 第一次去舞會要注意什麼
  2. Salsa、Bachata、Swing 三句話分辨
  3. 台北哪裡有初學課
  4. 一個人去舞會會不會很尷尬

### 讀完之後　最弱，中位觀看 118、追蹤 4 人
- 故事線：用具體事件開場，書名放後面（聖母峰 249、超級盃 157）
- 工具線「這本書的三個方法」：直接把書變成可以照做的清單

### 咖啡101
兩條線都已經有，維持現狀即可。
注意它的瓶頸是分發不是內容（停留 22.2 秒全站最高、觀看中位數只有 316）。

## 怎麼判斷有沒有效

用「每千次觀看漲粉」，不要用觀看數。
咖啡101 的 13.4 是你自己做得到的基準，其他頻道現在 0.9 到 3.6。

每週拉一次 insights，比對兩個快照之間的追蹤變化與觀看變化即可算出。

## 限制

- 八個頻道的樣本，相關係數看起來高但 n=8，不能當定論。
- 11/19–11/25 只有六天，單一爆款（肯亞品種 +4,514）影響很大。
- 轉換率受帳號規模影響：粉絲基數小的頻道百分比天然偏高。
- 工具線的效果要連續做 4–6 則才看得出來，不要發兩則就下結論。
