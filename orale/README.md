# Órale 西語

墨西哥西班牙文學習網頁，給台灣人用（中文全用台灣用語）。免登入，打開就能用。

線上版：https://jay0916746661.github.io/jimframe-site/orale/

## 功能
- 單字庫、閃卡、錯題本（連對 3 次才畢業）
- 第一階翻譯、第二階問答、第三階真人對話、8 個情境任務
- 跟讀發音評分、過去式特訓、每日西文日記
- 主題課：旅行、巴恰塔、潛水、教中文、街頭口語與髒話、墨西哥美食／節日／文化、台灣文化、音樂
- 學習方向心智圖、每週和上週比較

## 資料與 AI
- 進度存在瀏覽器（localStorage），不用帳號。
- AI 功能選用：在「我」貼上自己的 Anthropic API 金鑰，直接從瀏覽器呼叫，費用算在自己的帳號。
- 單一 `index.html`，沒有建置步驟。
