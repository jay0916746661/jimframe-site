## 這是什麼
Social Dance 101 的互動網站：社交舞族譜、世界舞池地圖、時間軸、舞者故事、小測驗。整個網站只有一個 `index.html`。網址 https://socialdance101tw.github.io。

## 怎麼用／怎麼改
直接改 `index.html`。改大段之前先下載一份備份。手機版要確認 390px 寬不會橫向捲動。

## 要注意
這個 org 目前**沒有授權給 Claude 的 GitHub App**（只能讀不能推）。要讓 AI 改它：到 https://github.com/apps/claude/installations/select_target 把 socialdance101tw 加進去，或用 Antigravity 改。

### 怎麼修（不用 Claude 也做得到）
1. 小改字：在 GitHub 網頁打開檔案 → 右上角鉛筆 ✏️ → 改完按 Commit changes。
2. 大改：用 Antigravity（Gemini）開這個 repo，第一句貼：「先讀 README.md，照裡面的說明改，改完給我分支名＋PR 連結，不要直接改 main。」
3. 改壞了：GitHub 網頁 → Commits → 找到改壞前那一版 → 點 `<>` 看舊檔，複製回來。**不要刪 repo、不要 force push。**
