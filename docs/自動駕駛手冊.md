# 自動駕駛手冊｜Claude 降到 Pro 之後，jimframe-site 怎麼自己跑

2026-11-28 整理。配合 Drive「AI 共同大腦」的〈20 美金操作手冊〉一起看：那份講「誰做什麼」，這份講「這個 repo 裡的機器怎麼跑、壞了怎麼修」。

**一句話**：發文、配音、數據、週報、庫存、失敗通知全部自己跑；寫稿改按一個按鈕叫 Gemini 寫；只剩「渲染影片」和「最後判斷」需要人或 AI 動手。

---

## 1. 你只要做一次的設定（約 10 分鐘）

1. **貼 Gemini 金鑰**
   - 到 https://aistudio.google.com/apikey 按「Create API key」，複製。
   - GitHub 打開 jimframe-site → Settings → Secrets and variables → Actions → **New repository secret**
   - Name 填 `GEMINI_API_KEY`，Secret 貼金鑰 → Add secret。
   - 注意：Google AI Pro 年繳**不包含** API 額度。AI Studio 的金鑰有免費額度，個人寫稿通常夠用；用超過會回 429，程式會自動等一下再試。若要付費，在 AI Studio 綁帳單即可，程式不用改。
   - （可選）同一頁的 **Variables** 分頁新增 `GEMINI_MODEL`，例如 `gemini-pro-latest`。不填就用 `gemini-flash-latest`；模型被改名時程式會自動挑最新可用的 flash。
2. **確認收得到通知**：GitHub 右上頭像 → Settings → Notifications → 「Participating, @mentions and custom」勾 Email（和 GitHub App 推播）。系統出事時會在 Issue 裡 @你。
3. **手機裝 GitHub App**（可選）：Issue 通知直接推到手機。

## 3. 日常怎麼用

### 每天（0 分鐘）
什麼都不用做。有事會收到 Email／App 通知〈🚨 系統需要處理〉。全部恢復時那個 Issue 會自己關掉。
想看狀況：打開 [`tools/watchdog/status.md`](../tools/watchdog/status.md)（每天 08:13 更新，有完整庫存表）。

### 每週一（5 分鐘）
收到〈📊 IG 週報〉通知 → 看最上面 5 行白話結論。

### 要補貨時：叫 Gemini 寫稿（手機也可以）
1. GitHub 網頁打開 jimframe-site → **Actions** → 左邊選「Gemini 寫稿（手動）」→ 右邊 **Run workflow**。
2. 選頻道、種類：
   - `選題`：給你 10 個新題目（會自動避開佇列裡做過的）。
   - `單集稿`：題目欄填 1 個或用 `；` 分隔多個（一次最多 10 集）。會產生完整稿（開場字卡、口白、分鏡、英文字幕、IG 文案、Threads、出處、待查）＋一個只有口白的 `_口白.txt`。
   - `文案`／`Threads`：只要貼文文字。
3. 約 1–3 分鐘後，草稿在 `drafts/<頻道>/`，執行頁的 Summary 也看得到全文。
4. 勾「順便配音」會用第一集的口白觸發 ElevenLabs（會扣點數），mp3 在「ElevenLabs TTS（手動）」最新一次執行的 artifact。

**調整寫法不用改程式**：改 `tools/gemini-writer/channels/_共通.md`（全部頻道）或 `channels/<頻道>.md`（單一頻道）。

### 草稿 → 上線（交給 Antigravity）
可以直接貼給 Antigravity 的指令：

```
請在 jimframe-site 做一集上線：
1. 讀 docs/自動駕駛手冊.md 和 tools/video-engine/jazz101/README.md。
2. 用 drafts/<頻道>/<檔名>.md 的口白與分鏡；mp3 用我給你的 speech.mp3。
3. 照 README 對時、找照片（Wikimedia／Openverse，記下作者授權）、渲染兩版影片。
4. 影片放 social/media/<頻道>/，25MB 內（CRF 20、最高 5Mbps）。
5. 在 ig_queue.csv 和 queue.csv 各加一列「待發」，時間接在該頻道最後一則之後；改 CSV 用 QUOTE_ALL。
6. push 前先 git pull；不要 git add -A；只 add 你新增的檔案。
回件給我：檔案清單、佇列新增的列、哪裡不確定。
```

## 4. 壞了怎麼修

| 通知裡看到 | 原因 | 修法 |
|---|---|---|
| 🔴／⚠️ 庫存 | 某頻道排到的日期剩不到 10 天 | 用 Gemini 寫稿補貨；不打算補的頻道（例如改名中）可以忽略，同一件事不會每天重複通知 |
| ❌ IG 失敗 2207085 | Meta 暫時錯誤，重試 3 次仍失敗 | 到 IG 確認沒有半成品 → 佇列改新時間 → 狀態改回「待發」 |
| ❌ IG 失敗「素材處理失敗」 | 影片格式或大小不對 | 重新輸出（CRF 20、≤5Mbps、≤25MB）再改回「待發」 |
| ❌ IG 逾時 | 超過預定 3 小時沒發 | 同上：改時間＋改回「待發」 |
| ❌ 試用 Reel 被拒 2207081 | 帳號粉絲不到 200 | trial 欄清空，改一般發文 |
| ⏸️ 卡住 | 過了 6 小時還是「待發」，代表發文 workflow 沒在跑 | Actions 頁看 IG／Threads 發文是否被停用（Enable workflow）；或 Secrets 權杖失效 |
| 🖼️ 素材不見 | 48 小時內要發的貼文，檔案不在 repo | 把檔案補進 `social/media/<頻道>/`，或改時間 |
| 🔑 Meta／Threads 權杖 | 權杖過期或帳號沒勾到 | 照 Drive SOP 06 重新產生，**整份覆蓋** Secret；改完跑「IG／FB 發文」check 模式 |
| 📅 到期提醒 | `tools/watchdog/reminders.csv` 裡的日期快到了 | 照提醒做；做完把那列日期改成下一次到期日 |
| 🛑 Actions 失敗 | 某個 workflow 紅燈 | 點通知裡的連結看最後 20 行錯誤 → 貼給 Gemini（Antigravity）照本手冊修 → 週三給 Claude 驗收 |
| 網站部署失敗 | 精簡包超過 950MB 或 push 太頻繁 | 等下一次 6 小時重建；連續失敗才處理（看 CLAUDE.md 的「網站部署」） |
| Gemini 寫稿失敗「沒有 GEMINI_API_KEY」 | Secret 沒貼或名字打錯 | 回第 1 節重貼，名稱一定是 `GEMINI_API_KEY` |
| Gemini 回 429 | 免費額度用完 | 隔天再跑，或一次少寫幾集 |

### 改提醒日期
編輯 `tools/watchdog/reminders.csv`（欄位：日期、事項、提前幾天提醒、怎麼做）。例如換了 Threads 權杖，就把那列改成 60 天後。

## 5. 新增的檔案在哪

| 位置 | 用途 |
|---|---|
| `.github/workflows/watchdog.yml` | 系統健康日報 |
| `.github/workflows/failure-alert.yml` | 失敗即時通知 |
| `.github/workflows/gemini-write.yml` | Gemini 寫稿 |
| `tools/watchdog/` | 日報程式、通知程式、到期提醒表、日報 `status.md` |
| `tools/gemini-writer/` | Gemini 呼叫程式、各頻道寫稿規則 `channels/`、週報白話結論 |
| `drafts/` | Gemini 寫好的草稿（不會自動發） |
| `docs/repo地圖與封存建議.md` | 29 個 repo 的總表 |

所有新程式都**只讀佇列、不改佇列、不刪檔**；寫入範圍各自限定（日報只寫 `tools/watchdog/`、`tools/stock/report.md`，寫稿只寫 `drafts/`，週報只寫 `social/reports/`），寫到別處會自己拒絕提交。
