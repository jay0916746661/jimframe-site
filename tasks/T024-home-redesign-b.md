## 要做什麼

### 1. 視覺規格（只改根目錄 `index.html` 的 CSS 與首頁區塊標記）
- 首頁固定深色：`<html>` 預設 `data-theme="dark"`。既有亮色變數保留、不要刪，但不再跟隨系統自動切到亮色。
- 色票（更新深色主題的 CSS 變數）：底 `#0A0A0C`、卡片 `#151518`、次層 `#1D1D22`、分隔線 `#2A2A30`、主文字 `#F4F1EA`、次文字 `#A6A5AE`、強調色 `#FF8A3D`（強調色按鈕上的字用 `#1A0E05`）。
- 字體：區塊大標題用 `'Noto Serif TC', 'Songti TC', serif`、字重 900；內文沿用現有 `--font-text`；英文小標與數字用 `'Space Grotesk'`。允許在 `<head>` 加**一條** Google Fonts css2 `<link>`（Noto Serif TC 900、Space Grotesk 500/700，`display=swap`），這是本任務對「外部資源」規則的唯一例外；字體載不到時版面不能壞。
- 每個區塊標題上方加橘色英文小標（12px、字距 0.22em），文字照設計稿。
- 卡片圓角 16–24px、照片卡片下緣加黑色漸層壓字，照設計稿。

### 2. 首頁區塊順序（由上到下）
1. **首屏**：滿版照片（高約 600px）＋上方透明導覽列（JF 標誌、JIMFRAME、語言切換 繁中／EN／한／日）＋襯線大標「舞池裡的你，都在這裡。」＋一行說明。首屏照片用一個常數 `HERO_PHOTO` 指定（先用 `photos/1031/A0009034.jpg`），方便 Jim 之後換。
2. **找自己和朋友**（現有 `#finder`）：改成浮在首屏照片下緣的卡片（上移約 72px 疊在照片上）。3 個自拍框、搜尋範圍切換、開始找、狀態文字、搜尋結果，**邏輯完全不動**，只換外觀。
3. **支持下一場拍攝**（現有 `#support`）：緊接在找自己下面。三個金額並排成卡片，中間「支持一晚拍攝」用橘框強調；保留 LINE 按鈕與 LINE ID 說明、Instagram 聯絡。
4. **每週精選**（現有 `#work` 的 carousel）：改成直式大卡橫向滑動，移除原本那段大標與說明（已移到首屏）。
5. **最新相簿**（現有 `#latest`）：第一本做成大卡（加 NEW 標籤），其後三本小卡一排。
6. **影片 · Bachata Crush**（現有 `#videos`）：第一場大卡加播放鈕，其餘列表列；保留完整版 NT$300／US$10 說明。影片瀏覽、下載、完整版流程不動。
7. **限動工具**卡片（連到 `./studio/`）。
8. **活動回顧**：兩張橫向卡片「萬聖節 2026」「Taiwan Bachata Crush 2026」，都連到 `./recap/`。
9. **活動相簿**（現有 `#archive`）：日期搜尋、場地篩選、相簿格、載入更多、標記 @jimframe 提醒，功能不動。
10. **預約拍攝**（現有 `#contact`）、頁尾、底部快捷列（現有 `.tabbar`）。
- 桌機寬度：內容維持現有 `--content` 最大寬度置中；首屏照片滿版；找自己卡片最大寬 560px 置中；各格線依寬度自動增加欄數。不需要另外設計桌機專屬版面。

### 3. 撤下過期內容
- 移除首頁最上面的 `#crush` 宣傳區塊（`crush-promo`），其中「找自己和朋友／看照片／看影片」按鈕的功能已由新首屏與各區塊取代。導覽列與 `.tabbar` 裡指向 `#crush` 的連結改指向頁首。
- 萬聖節：把 `index.html` 最後那段自動開關改成**只有網址帶 `?season=halloween` 才啟用**（拿掉日期判斷）。啟用時不再插入頂端 `hw-banner`。`hw*` 相框與特效函式保留不刪。

### 4. 新增活動回顧頁 `recap/index.html`
- 獨立靜態頁，沿用同一組色票與字體，頂端有「← 首頁」。
- 卡片一「萬聖節 2026」（2026.10.15 – 11.03）：按鈕「玩小遊戲」連 `../halloween/`、「看排行榜」連 `../halloween/`（若該頁有排行榜錨點就連錨點）、「特效相框」連 `../?season=halloween`；下面列出 10.30、10.31 兩本相簿的連結。
- 卡片二「Taiwan Bachata Crush 2026」（2026.10.15 – 10.18）：四晚各一列（連到首頁對應影片／相簿），底部按鈕「在這場活動裡找自己」連 `../#finder`。
- 照片數、影片數從現有資料帶，不要寫死設計稿上的數字。

### 5. 語言
- 所有新增或修改的介面文字都要進現有的翻譯字典（`CT.en`、`CT.ko`、`CT.ja` 那一套），四種語言切換後不能出現漏翻的中文。`recap/index.html` 也要支援同樣四種語言（可沿用同一份字典寫法，並記住使用者在首頁選的語言）。
